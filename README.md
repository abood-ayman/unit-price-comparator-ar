# Unit Price Comparator | مقارنة أسعار العبوات

Compare packages of the same product in different sizes and see which is really cheapest per kilo, liter or piece. Arabic interface.

**Live app:** https://abood-ayman.github.io/unit-price-comparator-ar/

**LinkedIn:** [Project entry](https://www.linkedin.com/in/abdullah-ayman-1678b737b/details/projects/)

![Unit Price Comparator, mobile view](docs/screenshot.svg)

This is a personal project, built with AI tools.

## Features
- Compare up to 3 packages by unit price (per kg / liter / piece)
- Automatic conversion between grams/kilograms and milliliters/liters
- Highlights the cheapest and shows exactly how much more the others cost (%)
- Great for grocery shopping and comparing family-size offers

## Note
Price is only one factor: quality, expiry date and whether you will use a bigger size before it spoils all matter too.

## Privacy
Everything runs in your browser. No data is stored or sent anywhere.

## Run locally
Open `index.html` in any browser. It is a single static page with no dependencies.
